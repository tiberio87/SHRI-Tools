# SHRI-Tools v5.4.0

## Nuove funzionalità

- **Filtri nello Storico upload**: due gruppi di filtri sopra la lista per consultare rapidamente i caricamenti.
  - **Categoria**: Tutti / Film / Serie TV
  - **Tipo**: Tutti / WEB-DL / Encode
  - I filtri si combinano tra loro e aggiornano lista e selezione.
- **Auto-categoria qBittorrent nel seed post-upload**: nella schermata di invio automatico al client, la categoria qBittorrent viene selezionata automaticamente in base alla categoria dell'upload (TV o Film), con match sui nomi delle categorie configurate. Resta modificabile manualmente.
